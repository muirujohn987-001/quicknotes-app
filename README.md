# QuickNotes — Personal Note Manager

QuickNotes is a simple, responsive web application that allows users
to create, organize, search, and delete personal notes. Users can
categorize notes as Personal, Work, or Study. The application uses
browser local storage to preserve notes between visits.

## Features

- Add notes with a category.
- Organize notes into Personal, Work, and Study categories.
- Search notes by their text.
- Delete individual notes.
- Validate input to prevent empty notes and notes exceeding 200 characters.
- Display the total number of notes.
- Save notes using browser local storage.
- Use a responsive layout for desktop and mobile screens.
- Display note creation dates and times.

## Technologies Used

- HTML5 — provides the page structure and semantic elements.
- CSS3 — styles the application and creates a responsive layout.
- JavaScript — implements note management, validation, searching, and storage.
- localStorage — saves notes in the browser.
